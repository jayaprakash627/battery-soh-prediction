How much battery is left,
without discharging it?

Measuring a pack's true capacity means running it flat — hours off the road. But every pack gets charged, and a charger already measures voltage, current and temperature. This model reads a few minutes of an ordinary charge and estimates what capacity remains, knowing nothing about the pack's history.

The number depends on how you split the data

Same model, same features, same cells — three ways of deciding what counts as "unseen". The gap between them is the whole story, and it is why most reported accuracy on this dataset means less than it looks like.

Why the first number is a mirage

Shuffling cycles puts cycle 100 in training and cycle 101 in test. They are nearly the same measurement of the same cell an hour apart, so the model can score well by interpolating between neighbours it has already seen. It answers "can you fill a gap in an experiment you already watched" — a question no fleet operator has ever asked.

Holding out a whole cell asks the real one: here is a pack you have never met. The honest number is the one this project reports, and the one the shipped model was chosen on.

Limits

  • —

Not in the model, on purpose

  • Cycle number. The strongest predictor in the dataset and useless in the field — it leaks the answer, and a second-hand pack does not arrive with its cycle count written on it.
  • Previous capacity. Same problem, worse: capacity is what is being predicted.
  • Cell identity. Eight cells is not enough to learn per-cell offsets that generalise. It is exactly enough to memorise them.
